# NGS 黄金实践段（开工提示词引用；按产品线勾选适用项）

> 用法：开工/收尾会话把这些条目作为"人类专家经验"附进提示词（来源：CellAgent 范式）。
> 本文件只收"跨任务不变的口径与纪律"，任务特有口径写进该任务 META 的 notes。

## 通用纪律

- 分析已在生产目录完成的（整理型任务），**直接引用生产结果，禁止重算**
- 逐 bin 大表（coverage/depth 类 summary 之外的一切大 csv/xls）**只取对应 png，不读内容**
- 结论草稿每句挂证据键（文件名+表号/图号），标"待审核"
- 参考模板的板块名与层级**保持不变**；"已完成列"是核对清单不是结果列
- 生产 config.yaml 是实验设计口径的唯一来源（物种/比对器/参数），不自行改选

## 状态与交付

- 收尾必补 methods/scripts/output 三字段，否则索引检索不到
- 交付包只含 scripts/ 与 results/（排除软链、元数据、既有压缩包）
- 产物不可覆盖：重做目录加 -v2 后缀

## 记忆纪律

- 任务 done 后提炼 0-3 条经验进 .kb/memory/（变更类经验必须写明"从 X 改为 Y，原因 Z"）
- 相同触发条件的旧经验有冲突 → 编辑旧条目并保留 superseded 历史，不新增副本
