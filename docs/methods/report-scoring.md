# 报告评分协议（整理型任务，能力 2 落地）

> 来源：GenoTEX 逐步对照评分 + BixBench 三梯度判分。

## 原则

1. 报告产出拆子步骤，每步对照"标准产物"（模板板块/参考任务同板块/客户验收点）独立评分
2. 三梯度：精确对照=1 · 部分对照=0.5 · 缺失或跑失败=0（**失败必须计 0 分入总分，不得跳过**）
3. 评分记录写进任务 `.meta.yaml` 的 notes 或独立 `results/score.md`，供回溯

## 子步骤基线（数据总结类任务）

| 子步骤 | 标准产物 |
|---|---|
| 板块齐全 | 模板 html 的板块清单逐一对应 |
| 数据归位 | tables/figures 与数据源对照表一一对应 |
| 结论挂键 | 每个结论句有真实存在的证据键 |
| 已完成列 | 客户"已完成列"逐项核对并标注 |
| 草稿标注 | AI 草稿声明与待审核标记 |

## 运行方式

- 收尾自评：收尾会话按上表逐行打分，总分写入 META notes（如 `score: 0.9`）
- <0.8：不置 done，先补齐
- 未来升级：胶囊化（标准产物打包+自动 diff），见 ROADMAP M3
